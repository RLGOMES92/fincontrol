# FinControl — Gestão Financeira

Aplicação web para organização financeira pessoal, reunindo acompanhamento de receitas e despesas, dívidas, reservas e ferramentas de análise em uma única interface.

## Módulos
- Visão Geral
- Ganhos e Gastos
- Dívidas
- Potes
- Reserva
- Fundo Preparado
- Valor do Tempo
- Cofre
- Assistente IA

## Recursos
- Importação de extratos OFX/CSV
- Cadastro e histórico de transações
- Controle de dívidas e parcelas
- Comparação de estratégias de amortização
- Backup e restauração
- Integração com Google Drive
- Modelo local para projeções do aplicativo
- Recursos de privacidade e proteção dos dados

## Objetivo
Facilitar a organização e o acompanhamento das finanças em uma única aplicação.
